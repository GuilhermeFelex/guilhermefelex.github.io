# FelexTech · Assets individuais (v5)

Todos os visuais estão separados em arquivos individuais para uso direto, sem pranchas, montagens ou cards.

- `01_logos_azul/`: logotipo horizontal sem/com slogan (com o último F inteiramente azul) e logotipo vertical aprovado.
- `02_logos_brancos/`: versões monocromáticas brancas dos logotipos, com transparência real.
- `03_icone_F_azul_transparente/`: F azul isolado, master original e PNGs de diversos tamanhos.
- `04_icone_F_branco_transparente/`: F branco isolado, PNGs com transparência.
- `05_favicon_F_transparente/`: favicon azul e branco *sem fundo*, PNG em tamanhos prontos + arquivos ICO.
- `06_favicon_F_fundo_escuro/`: favicon/app icon com fundo grafite, PNGs e ICO.
- `07_originais_aprovados/`: fontes PNG originais aprovadas que foram usadas para montar os derivados.

Para o seu portfólio Astro:
- Logo: `01_logos_azul/FelexTech_horizontal_sem_fundo.png`.
- Favicon transparente: `05_favicon_F_transparente/favicon_F_transparente.ico`.
- Favicon escuro: `06_favicon_F_fundo_escuro/favicon_dark.ico`.

**Transparência:** as imagens das pastas `sem_fundo` / `transparente` têm canal alfa real. As pastas de favicon dark possuem fundo intencional.
**Formato:** os masters finais são imagens PNG geradas; não forneço vetores SVG reconstruídos por aproximação como se fossem as artes originais.
